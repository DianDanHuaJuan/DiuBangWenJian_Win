## 〇、一句话

**同一套对等协议下的 Windows 节点**：互传常驻、NAS 可开关；对端默认进**指定文件夹**（媒体墙 + 目录树），可拨到**全盘**按文件夹浏览本机全部可读盘；单进程 + 托盘，不做安卓第二引擎；只与自有客户端配对，不面向第三方 WebDAV 挂载场景。

## 一、与安卓版的关系

### 1.1 保持一致（混网互通）

| 项 | 定案 |
|----|------|
| 角色 | 每台设备既是客户端也是服务端（对等），非「纯 NAS 服务端」 |
| 互传 | 常驻；不依赖对端开启 NAS |
| NAS | 用户开关；关 → 路由守卫 503；不运行时拆装路由 |
| 发现 | UDP 组播 announce，端口 **5245**（心跳 / 离线口径对齐安卓） |
| HTTPS 宿主 | 端口 **5244**；TLS 自签 + 指纹钉扎 + Bearer |
| 配对 | NASPAIR4 出示二维码 ∥ 8 位密码；删 peer 行 = 吊销（含全盘） |
| 会话 | 设备列表零长连接；进聊天 / 对端文件再建 WebSocket |
| API 读平面契约 | `rootId=library`（媒体墙）、`rootId=fs`（指定根目录树）、`rootId=extvol:…`（全盘卷内路径） |
| 分层纪律 | `core ↛ features`；`features ↛ features`；门禁 `tool/check_layer_deps.dart` |

### 1.2 刻意不同（桌面）

| 项 | 安卓 | Windows |
|----|------|---------|
| 后台 | NAS ON → FGS 第二 FlutterEngine | **单进程** UI isolate 即宿主 |
| 保活 | 前台服务 / MulticastLock 等 | **托盘**；关窗不杀监听 |
| 媒体索引源 | MediaStore | **指定文件夹扫描**（无系统 MediaStore） |
| 第二浏览面 | 「系统 / 外置」U 盘 | 「**当前目录 / 全盘**」盘符列表 |
| 参考旧仓 | — | 仅借桌面工程（托盘、Runner、裁剪 ffmpeg、打包脚本）；**不借**旧仓「单目录服务端 + Relay + 主人凭据」产品模型 |

### 1.3 旧版 `DiuBangNASServer_Windows` 用法

**可借鉴**：`window_manager` / `system_tray` / `launch_at_startup`、`sqflite_common_ffi`、裁剪后的 `ffmpeg.exe`、`bootstrap_windows` / Inno 打包、中文字体。  

**禁止照搬**：Relay、Bonsoir 替代 announce、主人 JWT/会话、控制中心替代三栏对等 UI、单共享目录取消媒体墙。

## 二、存储与对端浏览（核心定案）

### 2.1 指定文件夹（默认视野 + 唯一落盘）

- 初始默认：`下载\diubangfiles`（用户可改成任意文件夹）。
- **媒体墙**只索引该文件夹内图片 / 视频 / 音频（按扩展名分页；无 MediaStore）。
- **一切接收落盘**只进该文件夹：四分类目录 + 对端 `inbox/<peerFingerprint>/`；写满失败，**不**自动换盘。
- 对端默认模式：
  - `library`：该文件夹媒体墙；
  - `fs`：该文件夹目录树（文档 / 其他等）。
- 更换指定文件夹后：墙与落盘一起迁到新位置；旧位置不再作为墙 / 写根；全盘列表不受影响。

### 2.2 全盘模式（对端可切换）

- 拨码文案：**当前目录 / 全盘**（取代安卓「系统 / 外置」在 Windows 上的产品表述）。
- 拨到「全盘」：先展示本机**磁盘列表**，再按文件夹层级进入（与安卓外置 U 盘浏览同构：**无媒体墙、无整盘索引**）。
- **始终允许**：NAS 开启且已配对即可切全盘；**不做**本机「允许全盘」二次开关。
- 列表范围：当前 Windows 用户能访问的盘符与文件夹（含系统目录可读部分）；打不开的项仅本层报错。
- 路径安全：不跟随危险联接绕圈；删除等写操作对系统 / 保护目录拒绝（见 Q2 / Q3）。
- 缩略图：仅当前视口临时生成，不做整盘暖库。

### 2.3 对端能力矩阵

| 能力 | 当前目录（指定文件夹） | 全盘 |
|------|------------------------|------|
| 媒体墙 | ✅ | ❌ |
| 文件夹浏览 | ✅（`fs`） | ✅（盘符 → `extvol:`） |
| 预览 / Range 播视频 | ✅ | ✅ |
| 下载 | ✅ | ✅ |
| 上传 / 新建 / 改名 / 移动 | ✅ | ✅（仅普通目录） |
| 删除 | ✅ | ✅（普通目录；**二次确认**；系统 / 保护目录禁止） |
| 备份落入 | ✅（写指定根） | ❌（不写到全盘任意路径） |

### 2.4 与现有安卓客户端的兼容要点

- 卷列表接口继续走 `/api/v1/storage/volumes` + `extvol:` 列表 / content。
- 现安卓端会过滤 `isPrimary` 卷：Windows 导出盘符时须保证**可浏览卷对安卓可见**（例如均按非主卷暴露，或后续改客户端；移植期优先服务端侧兼容）。
- 拨码在 Windows 本机与对端 App 上统一理解为「当前目录 / 全盘」。

### 2.5 本机浏览

本机文件页与对端共用同一套根语义，不另造模型；产品核心验收以**对端浏览**为准。

## 三、运行时与桌面壳

| 项 | 定案 |
|----|------|
| 进程 | 单 Flutter 进程；NAS ON 时本进程 `bindSecure` + 组播 JOIN |
| 关窗口 | **缩进托盘**；NAS 状态保持；托盘「退出」才停监听并结束进程 |
| 开机自启 | **做**；设置里可关闭开机自启 |
| NAS 开关 | **持久化**；默认关；启动软件后恢复上次选择（含开机自启进托盘时） |
| 会话生命周期 | 仅当前登录用户；注销 / 切换用户后停止（不做 Windows Service） |
| 导航 | 左侧三栏：概览 / 设备 / 设置；内容对齐安卓；默认窗口约 1100×720 |
| 键鼠 | 双击打开、Ctrl/Shift 多选、Delete、方向键与 Esc 关预览、资源管理器拖入聊天 / 上传；右键：打开 / 发送 / 删除 / 在资源管理器中显示 |
| 配对 | 出示二维码 + 8 位密码；可输入对方密码；**首版不做摄像头扫码** |
| 选文件 | 指定文件夹媒体墙多选 + 系统文件选择器 |
| 防火墙 | 每用户安装，不强制管理员；首次引导放行 **TCP 5244**、**UDP 5245**；程序不静默改防火墙规则 |
| 网卡 | 跳过回环；**不因「私网」过滤地址**；默认选一个普通私网地址（自动优选可仍优先实体网卡）；设置可指定网卡 |
| 视频对端播放 | **仅 Range**；不做 HLS 转码 |
| 缩略图 | 可附带旧仓**裁剪版 ffmpeg**；优先系统 Shell 缩略图，失败再用自解码 / ffmpeg 抽帧 |
| 备份 | 保留；源为用户自选文件夹；进程在跑（含托盘）才执行；落入对端指定根 |
| WebDAV | 不面向第三方挂载；仅自有软件配对场景。实现上 WebDAV 与指定文件夹对齐即可，全盘能力以 App 拨码为准 |

| **Q10** | 配对 | **A**：出码 + 密码；可输对方密码；首版无摄像头扫码。 |

## 五、模块划分（移植）

```
lib/core/desktop/     # 窗口、托盘、开机自启、关窗策略（新）
lib/core/host/        # 单进程 HTTPS；Windows 无 FGS 迁出
lib/core/storage/     # 指定根、落盘、指定根媒体索引、盘符/全盘浏览、路径保护
lib/core/discovery/   # 组播；网卡选择；MulticastLock → 空实现
lib/core/device/     # 选文件/目录；权限/保活桥 → 空或桌面实现
lib/features/nas/     # handlers / 守卫 / 缩略图·ffmpeg；WebDAV 对齐指定根
lib/features/devices/ # 拨码「当前目录/全盘」、配对 UI、聊天互传
lib/features/preview/ # 画廊；无 HLS 依赖
lib/features/backup/  # 备份源改为文件夹选择
windows/ + packaging/ # Runner、托盘图标、裁剪 ffmpeg、安装包
```

**Owner 不变**：协议常量 `core/protocol`；NAS 插头 `features/nas`；互传端点 `features/devices`。平台差异进 core 可注入实现，避免 handlers 塞 `Platform.isWindows` 分支失控。

### 安卓桥在 Windows 上的归宿（摘要）

| 原能力 | Windows |
|--------|---------|
| FGS 双引擎 / NasRuntimeIpc | 单进程直调；IPC 空或旁路 |
| MediaStore | 指定根扫描 |
| Thumbnail MethodChannel | Shell + 自解码 + ffmpeg |
| system_stats / volumes | Win32 / 盘符枚举 |
| MulticastLock / 电池优化 / Presence FGS | 空实现 |
| photo_manager / 相册选择器 | 媒体墙 + `file_selector` |
| mobile_scanner | 首版不做 |
| media_kit Android libs | `media_kit_libs_windows_video` |
| sqflite 路径 | `sqflite_common_ffi` + 应用数据目录 |

## 六、施工分期

每期可构建、可与安卓机冒烟；禁止大爆炸重写协议。

| 期 | 目标 | 完成标准 |
|----|------|----------|
| **A 骨架** | `windows/` 工程、FFI 数据库、左侧三栏壳、依赖拆分（去掉挡住 Windows 的安卓专用强制链） | `flutter run -d windows` 进概览；不碰通道的单测通过 |
| **B 宿主与桌面** | 托盘、关窗、开机自启开关、NAS 持久化恢复、5244/5245、密码/出示码配对 | 安卓发现 Windows、配对写 peer；关 NAS → 503；开 NAS 可连 |
| **C 存储双模式** | 指定根墙 + `fs` + 落盘；拨码「当前目录/全盘」；盘符 `extvol`；路径保护与删除确认 | 手机默认见墙与指定目录；切全盘见盘符并下钻；上传进指定根 inbox |
| **D 媒体与键鼠** | Shell/ffmpeg 缩略图、Range 视频、拖入与右键、预览快捷键 | 网格/预览可用；ffmpeg 缺失时降级不崩 |
| **E 备份与安装** | 备份文件夹源、防火墙说明、裁剪 ffmpeg 打进包、Inno 安装包 | 干净机安装后可发现、可传、可全盘浏览 |

### 施工禁忌

- 不引入旧仓 Relay / 主人登录作为主信任模型。
- 不把发现改成 Bonsoir 替换 announce（可另议，非本文范围）。
- 不在 HTTP 线程弹 UI / 要权限。
- 全盘不做整盘媒体墙或持久缩略图库。
- 未改本文定案前，不擅自收窄 / 放宽 Q2 写删范围。

## 七、验收清单（混网）

1. Windows ↔ 安卓：组播发现、密码或扫码（安卓扫 Windows 码）、互传报价收妥。  
2. Windows 开 NAS：安卓进对端文件为**当前目录**，可见媒体墙与目录树；拨到**全盘**见盘符并浏览。  
3. 安卓上传 / 备份落入 Windows **指定文件夹**；全盘路径不作为落盘根。  
4. 全盘普通目录：下载 / 上传 / 建夹 / 改名 / 删（有确认）；保护目录删失败。  
5. 关 Windows 窗口：托盘仍可被发现（NAS 仍开时）；退出后不可达。  
6. 开机自启开：登录后托盘拉起并恢复 NAS；设置可关闭自启。  
7. 删配对后：原对端无法再访墙与全盘。
